## 沐曦主机内存故障

原始服务参数不变。首次 GPU 评测客户端导致服务被主机内存 OOM 杀死；重启原服务，并仅让 HTTP 精度客户端隐藏 GPU 后，精度评测完成。隐藏 GPU 的官方吞吐客户端会在 vLLM GPU 能力检测处报错，不能用这个方法复现吞吐。

恢复 GPU 可见的原版吞吐客户端后，本实例再次 OOM，服务退出，请求失败。检查时客户端 RSS 约17.94GiB，服务此前已接近64GiB主机内存上限。此证据只适用于本次镜像/实例，不能推广成所有64GiB配置必然失败。失败日志、退出状态、原始CSV均保留，未计入性能。

拟替换为同价4元/小时、64GB显存、120/128GB主机内存的C500。订单页返回库存不足；两页市场列表的上述大内存规格均售罄，未创建替换实例。旧实例完成备份后已关机。用户已授权更换一次上述规格：累计沐曦费用仍限16元，最晚2026-10-10 22:00 UTC关机。新订单服务条款仍需在实际接受时确认。

## 任务收尾

官方脚本每场景运行4次、跳过首轮、保留后三轮；只启动过一个天数正式吞吐任务，没有额外套三轮循环。

收尾脚本先等待该任务，检查两个场景各4次、每次请求全部成功、官方summary与原始CSV均值一致。有效后才尝试独立的vendor profiler，保持原始serve参数；诊断客户端负载不同，任何诊断速度都不算正式吞吐。Profiling可能受工具或预约时间限制；目前没有已测热点表。

本地限时备份进程会在预约结束前下载归档、核对SHA256并校验CSV；实际运行状态与后续输出在本地 `baseline-results/tianshu/collector-status.json`、`benchmark-validated-summary.json`，不能把“已启动收尾脚本”当作“已完成实验”。
